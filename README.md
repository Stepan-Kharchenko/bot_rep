# Teacher bot
## О проекте
Это учебный проект, разработанный в качестве финального проекта курса *Код будущего*, а также идущий в резюме.
## Описание
Это бот, написанный для помощи учителям по физике и математике на основе библиотеки vkbottle. Помогает учителям - тем, у кого есть права админа - добавлять задания, составлять тесты, управлять учениками и просматривать статистику.

## Установка
Для запуска приложения вам необходим Python, а также несистемные библиотеки vkbottle и dotenv
1. Скачать Python для Windows через браузер с официального сайта, для Linux и macOS в терминале `sudo apt install idle` и `brew install idle` соответственно 
2. В терминале прописать команды `pip install vkbottle` и `pip install dotenv`
3. Создать ВК сообщество и выполнить в нем необходимые для использования API vkbottle настройки, получить токен (ключ доступа). Подробнее в пункте управление сообществом.
4. Добавить в корень проекта файл secret.env и там прописать:
    * TOKEN = "токен_вашего_бота"
    * admin = "id админов через пробел"
5. Запустить файл main.py
## Структура проекта и краткое описание работы
```
/bot_rep
    keyboards.py
    main.py
    utils.py
    secret.env
    /database
        create_table.py
        learning.db
    /images
        images.pnj/jpeg ...
        img.py
    /scripts
        __init__.py
        registration.py
        test.py
        /admin
            __init__.py
            add.py
            stat.py
            user_control.py
```
* main.py - точка входа, содержит хендлеры:
  * start (для регистрации пользователей) - обрабатывает /start или Начать, вызывает сценарий scripts/registration.py
  * cancel (Вызывет главное меню) - обрабатывает /help или Отмена
  * test (Для прохождения теста) - обрабатывает /test, вызывает сценарий scripts/test.py
  * stat (Для просмотра своей статистики) - обрабатывает /statistic
  * admin (Для учителя) - обрабатывает /admin, вызывает сценарий scripts/admin/, инициализирует админ-панель
  * callback (Для обработки Callback-кнопок) - обрабатывает составление теста (есть в картинке выше) и регистрацию пользователя
* utils.py - содержит системные функции для валидации, управления БД и вспомогательные функции, которыми *не хочется засорять код*
* keyboards.py - содержит почти все клавиатуры проекта
* scripts/ - содержит все сценарии проекта, для админ-панели, в силу размера ее кода, создана отдельная папка
  * registration.py - регистрация
  * test.py - прохождение теста
  * admin/
    * add.py - добавление задания
    * stat.py - получение статистики
    * user_control.py - управление правами админа, удаление ученика, составление теста
* database/
  * create_table - функции для управления БД, чтобы каждый раз не вызывать
    ```python
    with sqlite3.connect() as conn:
        cursor = conn.cursor()
        cursor.execute("...")
        conn.commit()
    ```
  * learning.db - база данных
* images/ - еще недоработано
